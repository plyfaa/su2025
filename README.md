# Plyfaa's Replication Project Template

Online replication of Su, Qiu & Ding (2025), Experiment 1a, built in jsPsych and hosted on GitHub Pages.

For visually testing the paradigm: https://plyfaa.github.io/su2025/index.html?sona_id=INSTRUCTOR&sample=test

## Links and the `sample` tag

The `sample` part of the link goes into the saved file names and into a `sample` column. Test runs and pilots stay separate from SONA data.

| Who | Link ends in | Saved as |
|---|---|---|
| SONA participants | `?sona_id=%SURVEY_CODE%` | `main` (the default) |
| Pilot A | `?sona_id=...&sample=pilotA` | `pilotA` |
| Testing | `?sona_id=INSTRUCTOR&sample=test` | `test` |

File names and how to share data: see [data/README.md](data/README.md).
